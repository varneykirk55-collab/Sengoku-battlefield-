# Asset provenance

- **Placeholder audio** (`audio/sfx/**/TEMP_*.wav`, `audio/music/TEMP_*.wav`): generated by
  `tools/audio/build_audio.py`. It uses procedural generators copied unchanged from the owner's
  ASHIGARU project (`tools/audio/ashigaru_synth.py`, original synthesis offered there under CC0 1.0)
  plus new generators written for this project (matchlock ignition, battle cries, battle beds,
  objective cues, conch horn, music). Blade clash/block sounds (`TEMP_*_kengeki_*`) are
  procedurally generated placeholders copied from the owner's Kengeki project. No recordings or
  third-party sample libraries are used. All of it is temporary and meant to be replaced.
- **Rōnin character** (`assets/characters/ronin/`) and **Katana** (`assets/weapons/Katana.glb`): the
  owner's supplied models, copied unchanged from ASHIGARU for use as placeholders. The Rōnin's kimono
  tint and the sashimono banners are applied at runtime; the source files are not modified.
- **Engine**: Godot 4.7.2, MIT License. https://godotengine.org/license/

Kengeki and ASHIGARU were only read from; nothing in those repositories was changed.

- **Battlefield environment overhaul** (`scripts/battle/battlefield.gd`, `prototype_ground.gd`,
  Multimesh pines/bamboo/grass, procedural materials, golden-hour sky/sun): original code and
  procedural primitives generated in-engine for this project (Bot 3). No third-party meshes,
  textures, or sound. See [docs/ENVIRONMENT.md](docs/ENVIRONMENT.md).

- **Environment v3 assets** (`assets/env/meshes/*.glb`, `assets/env/textures/*.png`,
  `assets/env/terrain_blend.gdshader`, `scripts/battle/env_meshes.gd`): original procedural /
  Blender-authored content created for this project (Bot 3). No third-party store meshes or
  photos. Textures are synthetic noise; meshes are primitives arranged into Sengoku silhouettes.
